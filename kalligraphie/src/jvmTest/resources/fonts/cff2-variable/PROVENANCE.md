# Provenance — SyntheticVariable-CFF2.otf

- **Source:** two synthetic CFF2 masters built in memory by
  `build_cff2_variable_fixture.py` (fontTools 4.65.0). Both masters share the
  `.notdef` glyph and the same `A` triangle outline except for the apex height
  (200 in the default master, 300 in the bold master).
- **Generated by:** `fontTools.varLib.build` merging the two masters over a single
  `wght` axis, producing a real variable CFF2 charstring with a `blend` operator
  over an ItemVariationStore region.
- **Why:** the static CFF2 fixture does not exercise `vsindex`/`blend`; this one
  does. At the default instance the region scalar is zero, so the audited default
  outline keeps the master-0 apex (200): a decoder that mis-computes the default
  scalar would instead report 300.
- **Oracle:** `A-outline.txt` is produced by an independent fontTools
  `RecordingPen` on the generated `.otf`, in design units.
- **Regenerate:**
  `python3 kalligraphie/src/jvmTest/resources/fonts/cff2-variable/build_cff2_variable_fixture.py`
  (requires `fonttools`).
- **Scope note:** the portable route materializes the default instance only; a
  non-default variation instance is not supported.

# Provenance — LiberationSans-CFF2.otf

- **Source:** `LiberationSans-Regular.ttf` from the audited `fonts/liberation`
  fixture in this repository (Liberation fonts, SIL Open Font License 1.1; see
  `../liberation/OFL-1.1.txt`).
- **Generated by:** `build_cff2_fixture.py` using fontTools 4.65.0
  (`FontBuilder` with `setupCFF2` and `T2CharStringPen`). The `.notdef` and `A`
  outlines are converted losslessly from the source quadratic outlines to CFF2
  cubic charstrings with no width operand. Only `.notdef` and `A` are retained.
- **Type:** static CFF2 (no variation store). Variable CFF2 `blend` deltas are
  covered by synthetic unit tests, not by this fixture.
- **Oracle:** `A-outline.txt` is produced by an independent fontTools
  `RecordingPen` on the generated `.otf`, not by Kalligraphie, in design units.
- **Regenerate:**
  `python3 kalligraphie/src/jvmTest/resources/fonts/cff2-liberation/build_cff2_fixture.py`
  (requires `fonttools`).
- **Purpose:** exercise the portable CFF2 outline route end to end through the
  embedded catalog without depending on a system-installed font.

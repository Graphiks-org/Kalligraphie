# Provenance — LiberationSans-CFF.otf

- **Source:** `LiberationSans-Regular.ttf` from the audited `fonts/liberation`
  fixture in this repository (Liberation fonts, SIL Open Font License 1.1; see
  `../liberation/OFL-1.1.txt`).
- **Generated by:** `build_cff_fixture.py` using fontTools 4.65.0
  (`FontBuilder` with `setupCFF` and `T2CharStringPen`). The `.notdef` and `A`
  glyph outlines are converted losslessly from the source quadratic outlines to
  CFF1 cubic charstrings. Only `.notdef` and `A` are retained; advance widths are
  set to 2048 design units.
- **Oracle:** `A-outline.txt` is produced by an independent fontTools
  `RecordingPen` on the generated `.otf`, not by Kalligraphie. It records
  `M`/`L`/`C`/`Z` commands in design units and is the audited expected outline.
- **Regenerate:**
  `python3 kalligraphie/src/jvmTest/resources/fonts/cff-liberation/build_cff_fixture.py`
  (requires `fonttools`).
- **Purpose:** exercise the portable CFF1 (`CFF `) outline route end to end
  through the embedded catalog without depending on a system-installed font.

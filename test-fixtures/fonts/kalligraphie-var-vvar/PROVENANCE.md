# Provenance — KalligraphieVarVVAR.ttf

- **Source:** synthetic, generated in memory by `build_variable_vvar.py`
  (fontTools 4.65.0). Project-owned; no third-party font data or licence applies.
- **Why:** no fixture carried a non-zero `VVAR` advance-height delta. Every
  existing variable fixture keeps a constant vertical advance (the audited
  `NotoSansJP-VerticalFixture.ttf` has no `VVAR`, and kffi's `KffiVar.ttf` has a
  `VVAR` whose `AdvHeightMap` is absent), so the vertical location transport of
  the metric route could not be exercised against a real font. This fixture
  moves `vmtx['A'].advanceHeight` with the `wght` location.
- **Generated by:** `fontTools.fontBuilder.FontBuilder` for the base tables plus
  a hand-assembled `VVAR` (`varLib.builder.buildVarRegionList` /
  `buildVarData` / `buildVarStore` / `buildVarIdxMap`). A fixed `head` LONGDATETIME
  (`3_600_000_000`) makes the output byte-reproducible.
- **Structure (verified with fontTools 4.65.0 by decompiling the generated bytes):**
  `unitsPerEm = 1000`; glyph order `['.notdef','A']`; `cmap 0x41 → A` (gid 1);
  `fvar` one axis `wght` (0/0/1000), no `avar`; `vhea`/`vmtx` give every glyph
  `(advanceHeight 1000, tsb 100)`; `VVAR` version 1.0 with one region
  `(0.0, 1.0, 1.0)` on `wght`, one `VarData` with rows `[[0], [200]]`, and a
  present `AdvHeightMap` (`{.notdef: 0, A: 1}`). At the default location the
  region scalar is zero, so the advance equals the `vmtx` base; at the axis
  maximum it is `1000 + 200`.
- **Oracle (independently computed, fontTools 4.65.0 + HarfBuzz 14.4.0):** glyph `A`
  advance height by normalized `wght` (`VarStoreInstancer` takes normalized coordinates):

  | normalized `wght` | `VarStoreInstancer` row 1 | `vmtx['A']` + delta | `hb-shape --direction=ttb` `ay` |
  |---|---|---|---|
  | `0.0` | `0` | `1000` | `-1000` |
  | `0.5` | `100` | `1100` | `-1100` |
  | `1.0` | `200` | `1200` | `-1200` |

  HarfBuzz's vertical advance is negative (upward-positive); the engine flips it to
  a positive `advanceHeight` through `toPhysicalVerticalCoordinate`.
